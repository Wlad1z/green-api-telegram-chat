# Чат для GREEN-API (Telegram)

Тестовое задание на React-разработчика. За основу взят апи для Telegram.

**Демо:** https://dem-portf.ru/test/green-api/

## Что умеет

- вход по `idInstance` и `apiTokenInstance` (плюс `apiUrl`, он у каждого инстанса свой)
- новый чат по номеру телефона
- отправка текста, Enter отправляет, Shift+Enter переносит строку
- приём сообщений, ответ собеседника появляется в чате сам
- несколько чатов, счётчик непрочитанных
- на телефоне чат открывается поверх списка

Только текст. Картинки, файлы и остальные такие входящие сообщения показываются заглушкой.

## Что использовал

React, TypeScript, Vite, Zustand (состояние), CSS Modules. Для тестов Vitest.

## Как запустить

Нужен Node.js 20.19+ (или 22.12+).

```bash
npm install
npm run dev
```

Открыть нужно **http://localhost:5173/test/green-api/**, именно с этим путём. Он задан в `vite.config.ts` (`base`), потому что я выкладывал проект в подпапку своего сайта. Если запускать локально без подпапки, `base` можно убрать.

Другие команды: `npm run build` (сборка), `npm run lint`, `npm test` (тесты).

## Как это устроено

- `src/api/greenApi.ts`: запросы к API.
- `src/hooks/useNotifications.ts`: получение сообщений. Это бесконечный цикл: `ReceiveNotification`, потом обработка, потом `DeleteNotification`. Уведомление удаляется всегда, иначе очередь застрянет на нём. При выходе цикл останавливается через `AbortController`.
- `src/lib/notifications.ts`: разбор уведомлений и обновление чатов.
- `src/store/chatStore.ts`: состояние, оно же сохраняется в `localStorage`.

## Тесты

Два файла, оба на `npm test`: проверка номера телефона (`src/lib/phone.test.ts`) и разбор уведомлений (`src/lib/notifications.test.ts`).

## Что не доделано и почему

- **Нет двойных галочек «прочитано».** Статус `read` у Telegram-версии API не приходит: я проверил и уведомлениями, и журналом `lastOutgoingMessages`, там всегда `delivered`, даже когда собеседник уже ответил. Обработка `read` в коде есть, заработает, если API начнёт его отдавать.
- **Токен лежит в `localStorage`.** Для тестового сделал так, потому что бэкенда нет.
- **История не подгружается.** Видны только сообщения, пришедшие или отправленные, пока приложение открыто (и то, что сохранилось в браузере).
- **Сообщения, отправленные с телефона**, показываются только в уже открытых в приложении чатах.
